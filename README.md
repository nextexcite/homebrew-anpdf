# homebrew-anpdf

Homebrew tap for [anPDF](https://github.com/nextexcite/anPDF).

```sh
brew tap nextexcite/anpdf
brew trust --formula nextexcite/anpdf/anpdf
brew install anpdf
```

Current Homebrew requires trusting non-official tap formulae before `brew install`
(see Homebrew's `docs/Taps.md`); `brew trust --formula` grants trust to this one
formula only.
